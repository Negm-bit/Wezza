موقع عيد ميلاد زوزو — النسخة التفاعلية

1) كلمة السر
كلمة السر الحالية: 20/6
لتغييرها افتح content.js وعدّل:
password: '20/6'

2) شاشة الباسورد
الشاشة مقصودة تكون بسيطة جدًا وتظهر فقط: «اكتبي الباسورد» + خانة الباسورد + زر السهم.

3) الاحتفال بعد الـSplash
بعد الضغط على زر الدخول في الـSplash، يظهر مشهد احتفالي لمدة 20 ثانية:
- بالونات مكتوب عليها «بحبك»
- شرائط/كونفيتي ملونة
- صواريخ/ألعاب نارية متحركة
- Popup: «كل سنه وانتي طيبه ي زوزووو»
بعد 20 ثانية يختفي المشهد تلقائيًا.

4) تعديل البروفايل
ضع الصورة الجديدة داخل assets ثم غيّر في content.js:
profile: 'assets/اسم-الصورة.jpg'

5) تعديل الاسم والنصوص
كل النصوص الأساسية موجودة داخل content.js في قسم text.
غيّر النص بين علامات الاقتباس فقط.

6) تعديل الكابشنات
الصور: D.photos
الفيديوهات: D.videos
الشات: D.chats
مثال:
{ file: 'photo-01.jpg', caption: 'اكتب الكابشن هنا' }

7) الأغاني
ضع ملفات MP3 داخل مجلد audio بهذه الأسماء:
song-01.mp3 إلى song-14.mp3
أسماء الأغاني التي تظهر على الموقع موجودة في D.songs داخل content.js.

8) رفع الموقع على GitHub Pages
ارفع محتويات هذا المجلد إلى repository، ثم فعّل GitHub Pages من Settings > Pages.

ملاحظة: حماية كلمة السر في GitHub Pages هي حماية واجهة فقط وليست تشفيرًا حقيقيًا؛ لأن الموقع Static.
